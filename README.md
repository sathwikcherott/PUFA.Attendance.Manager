# PUFA Manager Hub

PUFA Manager Hub is an Android football academy management app built to simplify player operations, attendance tracking, fee management, and report exports through a clean and structured workflow.

Built using Kotlin and Jetpack Compose, the project focuses on scalability, maintainability, and practical real-world usage instead of rushed feature dumping.

---

## Features

### Dashboard

* Operational overview cards
* Expandable payment defaulters section
* Quick visibility into academy activity

### Attendance Management

* Live attendance marking
* Present / Absent state management
* Batch filtering
* Attendance editing workflow
* Color-coded attendance states

### Fee Management

* Paid / Unpaid tracking
* Fee presets support
* Custom fee entry
* Exemption system
* Payment sorting and status indicators

### Player Management

* Player creation and organization
* Batch-based filtering
* Search functionality
* Year of birth display system
* Batch editor support

### History System

* Historical attendance editing
* Historical payment editing
* Save workflow with change detection
* Batch and month filtering
* Segmented operational history sections

### Export System

* Attendance PDF generation
* ZIP export handling
* Android share sheet integration
* Batch and month based report exports
* Planned player list export system

## Development Philosophy

This project is being built with a long-term architecture-first mindset.

Core principles:

* Stability before cosmetics
* Incremental development
* Modular architecture
* Rollback-first workflow
* Commit before risky changes
* Backend systems before UI polish

The project avoids giant AI-generated rewrites and focuses on isolated, maintainable feature integration.

---

## Architecture Direction

The app is gradually transitioning toward:

* Isolated screen files
* Reusable composables
* Centralized theming
* Modular export utilities
* Cleaner navigation structure
* Maintainable scaling for future features
